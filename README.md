# Fundraise — virtual fundraising bootcamp

React + Vite + TypeScript + Tailwind CSS. Converted from approved HTML preview v13.

## Run locally
Node.js 20.19+ or 22 recommended.
```sh
npm install
npm run dev
```
Production: `npm run build`, then `npm run preview`.

Components are numbered by page order; newest sections have highest numbers. Assets are imported from src/assets. Original CSS and scroll behavior are retained for fidelity. No registration backend or multi-page routing. Replace fictional contact details and pending social links before publishing.
